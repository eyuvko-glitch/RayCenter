# RayCenter — Android-проект (этап 1)

Первая техническая сборка для Android 11+.

## Реализовано
- Русскоязычный экран приложения.
- Обнаружение USB-устройств через Android USB Host API.
- Поиск интерфейса USB Video Class (UVC) и запрос разрешения Android.
- Отображение VID/PID и числа интерфейсов.

## Пока не реализовано
Живое MJPEG-видео, OpenCV и расчёт смещения центра пятна относительно внутренней окружности сопла. Это только тест обнаружения USB-камеры, не полноценный измеритель.

Телефон должен поддерживать USB Host/OTG. Не направлять рабочий режущий лазер на камеру; проверять только безопасным пилотным/тестовым режимом.
