# Техконтроль — Android-приложение

Ветка `tech-control-app` содержит отдельный проект технической отчётности для трёх объектов предприятия: ОРВХ, ЭЛ70 и ЭЛ19.

## Функции
- Выбор объекта сотрудником.
- Категории: ежедневный отчёт, неисправность, выполненные работы, осмотр оборудования, заявка на материалы, аварийная ситуация.
- Описание, оборудование/участок, принятые меры и приоритет.
- До 12 фотографий.
- Прямая отправка текста и фотографий в общую группу Telegram через Telegram Bot API.
- Настройки ФИО, токена бота и ID группы хранятся локально на телефоне.

## Сборка
GitHub Actions автоматически собирает debug APK при каждом push в ветку `tech-control-app`. Готовый файл доступен во вкладке Actions → запуск сборки → Artifacts.

## Подключение Telegram
Добавьте своего Telegram-бота в общую группу. В приложении откройте «Настройки», укажите ФИО и токен бота, затем получите ID группы кнопкой или вставьте его вручную. Бот должен иметь право отправлять сообщения и фотографии в группе.

Токен хранится на устройстве, поэтому используйте отдельного бота для приложения и не передавайте APK с уже заполненным токеном посторонним. Если у бота настроен webhook, автоматическое получение ID через getUpdates не сработает — используйте ручной ввод chat_id.

Это тестовая версия: перед рабочим использованием проверьте отправку текста и фотографий в отдельной тестовой группе.
