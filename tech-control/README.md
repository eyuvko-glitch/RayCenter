# Техконтроль — Android-приложение

Ветка `tech-control-app` содержит отдельный проект технической отчётности для трёх объектов предприятия: ОРВХ, ЭЛ70 и ЭЛ19.

## Функции
- Выбор объекта сотрудником.
- Категории: ежедневный отчёт, неисправность, выполненные работы, осмотр оборудования, заявка на материалы, аварийная ситуация.
- Описание, оборудование/участок, принятые меры и приоритет.
- До 12 фотографий.
- Прямая отправка текста и фотографий в общую группу MAX через MAX Bot API.
- Настройки ФИО, токена бота и ID группы хранятся локально на телефоне.

## Сборка
GitHub Actions автоматически собирает debug APK при каждом push в ветку `tech-control-app`. Готовый файл будет доступен во вкладке Actions → выбранный запуск → Artifacts. Для установки также можно скачать APK из артефакта сборки.

## MAX
Создайте отдельного бота, добавьте его в группу и введите токен и chat_id в настройках приложения. Не помещайте токен в исходный код. Прямое подключение означает, что токен хранится на устройстве и потенциально может быть извлечён; используйте отдельного бота и отзывайте токен при компрометации.

Это первая тестовая версия. Перед рабочим внедрением проверьте отправку текста и фотографий в отдельной тестовой группе MAX.
