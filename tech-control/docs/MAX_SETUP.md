# Настройка MAX для приложения «Техконтроль»

1. Создайте отдельного чат-бота MAX для технических отчётов в кабинете разработчика MAX.
2. Создайте общую группу для отчётов.
3. Добавьте бота в группу и выдайте ему необходимые права на отправку сообщений.
4. В приложении откройте «Настройки» и введите ФИО сотрудника и токен бота.
5. Укажите ID общей группы MAX. Если доступно получение событий, нажмите «Получить ID группы из MAX». Иначе введите chat_id вручную.
6. Сохраните настройки и отправьте тестовый отчёт сначала без фотографии, затем с фотографией.

## Что попадает в MAX

Объект, категория, ФИО сотрудника, дата и время, оборудование/участок, описание, дополнительные сведения и приоритет для неисправностей и аварий. Выбранные фотографии прикладываются к сообщению.

## Важные ограничения

- Токен хранится в локальных настройках приложения. Его нельзя считать защищённым от извлечения с устройства. Используйте отдельного бота для этой системы.
- Не вставляйте токен в исходный код и не передавайте APK с уже заполненным токеном.
- При подозрении на компрометацию отзовите токен бота и создайте новый.
- Кнопка автоматического получения chat_id использует GET /updates для первичной настройки. Если бот подключён к webhook или MAX не возвращает события, укажите ID группы вручную.
- Это первая версия. Перед внедрением на все три объекта обязательно проверьте реальную отправку текста и изображений в тестовой группе MAX.
