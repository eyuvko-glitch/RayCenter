# Настройка Telegram для приложения «Техконтроль»

1. Откройте Telegram и добавьте существующего бота в общую группу технических отчётов.
2. Убедитесь, что бот может отправлять сообщения и фотографии в этой группе.
3. В приложении откройте «Настройки» и введите ФИО сотрудника и токен бота.
4. Чтобы определить ID группы автоматически, отправьте в группе команду или сообщение, затем нажмите «Получить ID группы из Telegram».
5. Если автоматическое получение не сработало, вставьте chat_id группы вручную. Для групп и супергрупп это обычно отрицательное число.
6. Сохраните настройки и отправьте тестовый отчёт сначала без фото, затем с фотографией.

## Что отправляется в Telegram

Объект, категория, ФИО сотрудника, дата и время, оборудование/участок, описание, дополнительные сведения и приоритет для неисправностей и аварий. Текст отправляется отдельным сообщением, фотографии — отдельными сообщениями Telegram.

## Важные ограничения

- Токен хранится в локальных настройках приложения и может быть извлечён с устройства. Используйте отдельного бота и не передавайте APK с уже заполненным токеном.
- Если у бота установлен webhook, Telegram не разрешает одновременно получать обновления через getUpdates. В этом случае укажите chat_id вручную.
- Для определения ID бот должен получить обновление из нужной группы. Если включён privacy mode, используйте команду, адресованную боту, либо временно настройте доступ к сообщениям в BotFather.
- Перед внедрением на все три объекта проверьте реальную отправку текста и изображений в тестовой группе.
