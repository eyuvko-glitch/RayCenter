# Сервер-посредник для приложения «Техконтроль»

Сервер принимает отчёт от Android-приложения и пересылает его в Telegram. Токен бота и ID группы хранятся в Cloudflare Workers Secrets, а не в APK.

## Развёртывание через Cloudflare

1. Войдите в Cloudflare и откройте **Workers & Pages**.
2. Нажмите **Create application → Create Worker**.
3. Назовите Worker, например `tech-control-relay`, и нажмите **Deploy**.
4. Откройте созданный Worker → **Edit code**. Замените демонстрационный код содержимым файла `worker.js` из этого каталога и нажмите **Deploy**.
5. Откройте **Settings → Variables and Secrets** и добавьте три переменные типа **Secret**:
   - `BOT_TOKEN` — токен существующего Telegram-бота.
   - `CHAT_ID` — ID вашей общей Telegram-группы (обычно отрицательное число, часто начинается с `-100`).
   - `APP_KEY` — длинный случайный пароль, который вы сами создаёте. Не используйте пароль от других сервисов.
6. После сохранения Secrets снова нажмите **Deploy** (если панель просит применить изменения).
7. Проверьте адрес Worker: откройте `https://АДРЕС-ВАШЕГО-WORKER/health`. Должен появиться ответ `{"ok":true,"service":"tech-control-relay"}`.

## Настройка Android-приложения

В разделе «Настройки» приложения укажите:
- **Адрес сервера отправки** — базовый HTTPS-адрес Worker, без `/api/report` и без завершающего пути.
- **Ключ доступа приложения** — то же значение, которое внесено в Secret `APP_KEY`.
- ФИО сотрудника.

Токен бота и ID группы в приложение больше не вводятся.

## Важно

- Добавьте бота в нужную группу и убедитесь, что у него есть право отправлять сообщения и фотографии.
- Не публикуйте значения Secrets и не вставляйте их в исходный код или APK.
- Приложение передаёт фотографии по HTTPS; сервер пересылает их по одной. Поддерживается до 12 фотографий, ограничение этого Worker — 10 МБ на фото.
- При ошибке Telegram сервер вернёт понятное сообщение. Если ошибка возникла на фотографии, текст отчёта мог уже попасть в группу.
- Этот Worker не предоставляет публичный метод настройки бота: менять Secrets может только владелец Cloudflare-аккаунта.
