# Сборка RayCenter APK

GitHub Actions workflow `.github/workflows/android-apk.yml` собирает debug APK и публикует его как артефакт `RayCenter-debug-apk`.

Откройте вкладку Actions репозитория, выберите Build RayCenter APK, дождитесь завершения и скачайте артефакт RayCenter-debug-apk. В ZIP находится `app-debug.apk`.

Это ранняя сборка: только обнаружение USB/UVC и запрос разрешения. Видео и измерение центровки ещё не реализованы.
